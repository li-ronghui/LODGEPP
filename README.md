# LODGEPP

Lodge++: High-quality Long-duration Dance Generation with Robust Choreography

## Initial code release

This repository currently contains an initial code snapshot imported from
[`li-ronghui/Lodge_plus_smpl`](https://github.com/li-ronghui/Lodge_plus_smpl)
at commit `5d82c5d2ea5540e3cbcd18b434bcdac403bf778e`.

The snapshot includes the Lodge++, DanceDiffusion, DiffusionNet, and EDGE code,
configuration files, and the small data assets tracked by the source repository.
Model checkpoints, training datasets, experiment outputs, Python bytecode, and
machine-specific editor settings are not included.

The current scripts still contain environment-specific paths and the upstream
repository does not provide a complete reproducible environment specification.
Setup instructions and cleaned entry points will be added in a later update.
